# Code of Conduct

All contributors to Tryzub Ledger are expected to follow a respectful and inclusive code of conduct.

## Our standards

- Be respectful in discussions.
- Avoid harassment, hateful language, personal attacks, or discriminatory remarks.
- Keep communication focused on the project, not individuals.

## Reporting

If you experience or observe unacceptable behavior, please report it through GitHub issues or directly to the repository maintainers.
