# Security Policy

Tryzub Ledger is an early-stage open-source project. If you discover a security issue, please report it in a GitHub issue marked `security` or contact the maintainers directly if available.

## Important

- The current admin control is protected by `ADMIN_TOKEN`, which is intended only for local development and early deployment.
- Do not deploy this token into production without replacing it with a stronger access control mechanism.
- Do not expose secret keys or credentials in repository files.
